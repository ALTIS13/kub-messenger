Готовим подключение

Сертификат проверяет оболочка приложения при своём HTTPS-запросе. Страницу рабочего пространства загружает WebView2 — он проверяет своё соединение отдельно, средствами Windows.

  1. Сеть Проверяем, что интернет есть и узел вообще отвечает.
  2. Сертификат Windows проверяет цепочку доверия сертификата, а оболочка сверяет его отпечаток с запомненным.
  3. Обновления Смотрим, вышла ли новая версия оболочки. Запуск это не задерживает.
  4. Рабочее пространство Открываем сам мессенджер: чаты, файлы и уведомления.
